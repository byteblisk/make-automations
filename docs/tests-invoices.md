# בדיקות: תרחיש החשבוניות

23 בנובמבר 2026. כל בדיקה היא מייל אמיתי שנשלח לכתובת ה-mailhook, ואחריו בדיקה של הטבלה ב-Airtable. הספקים במיילים הם שמות בדויים.

## הרצה ראשונה: נכשלה

המייל הראשון הגיע ל-Make, והריצה נעצרה בשלב הסיווג עם השגיאה "You are using old version of the app". התרחיש נבנה עם גרסה 1 של Make AI Toolkit, ו-Make מקבל היום רק את גרסה 2. Make כיבה את התרחיש ושלח מייל על כך. לא נשמר שום דבר ב-Airtable.

התיקון: שני שלבי ה-AI עברו לגרסה 2. בגרסה הזו צריך לבחור חיבור ומודל: Make's AI Provider, מודל medium. המייל שנשאר בתור עבר שוב ונשמר נכון (בדיקה 1 למטה).

## מה תוקן אחרי בדיקה 3

במייל של בדיקה 3 התאריך היה כתוב "Date paid: November 18, 2026", וה-AI השאיר את השדה ריק. ההוראה הקודמת ביקשה "תאריך החשבונית", והמודל לא חשב שתאריך תשלום בקבלה הוא התאריך הזה. ההוראה החדשה אומרת במפורש: תאריך החשבונית או תאריך התשלום בקבלה, בכל צורת כתיבה, מומר ל-YYYY-MM-DD. בדיקה 4 נבנתה כדי לבדוק בדיוק את זה, ועברה.
