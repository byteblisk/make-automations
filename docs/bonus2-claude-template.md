# בונוס 2: אוטומציה של מישהו אחר

לקחתי את התבנית "Send messages to Anthropic Claude and update records in Airtable using a custom webhook" (תבנית 14527) מספריית התבניות הציבורית של Make ויצרתי ממנה תרחיש בחשבון שלי. אלה השלבים בתבנית:

Webhook → Airtable Get a record → Anthropic Claude Create a Prompt → JSON Parse JSON → Airtable Update a record

בגרסה שבריפו יש גם שלב שישי, Webhook response, שהוספתי בשביל הדשבורד (ראו למטה).

## מה התאמתי

חיברתי את התבנית לטבלת הלידים של הדשבורד והוספתי לטבלה שני שדות: aiScore (ציון 1 עד 100) ו-aiSummary (סיכום קצר בעברית). ה-webhook מקבל מזהה רשומה של ליד, Claude קורא את פרטי הליד ומחזיר JSON עם ציון וסיכום, והתוצאה נשמרת בליד. יצרתי חיבור Anthropic משלי ב-Make, והמפתח לא נמצא בריפו.

שלושה דברים בתבנית לא עבדו כמו שהיא:

| מה | הבעיה | מה שיניתי |
|---|---|---|
| המודל | Claude 3.7 Sonnet כבר לא מופיע ברשימת המודלים של Make | Claude Haiku 5.5 |
| max_tokens | נשמר בתבנית כטקסט "1000", ו-Anthropic החזירו שגיאה 400 | המספר 1000 |
| הקלט של Parse JSON | הפנה ל-content של התשובה, אבל הפריט הראשון שם לא היה הטקסט, ולכן הקלט יצא ריק | rawResponse, הטקסט המלא של התשובה |

## הבדיקה

23 בנובמבר 2026. שלחתי ל-webhook את מזהה הרשומה של הליד L-1263 (רון כהן) והרצתי את התרחיש פעם אחת. כל חמשת השלבים עברו, והליד קיבל ציון 55 ואת הסיכום: "ליד מופנה עם תקציב גדול וערך של 25,000 ש"ח וענין ברור באתר תדמית וחיבור ל-CRM. עם זאת, הסטטוס עדיין חדש ואין פתיחות מיילים או ביקורים באתר, כך שהמעורבות נמוכה."

הריצה צרכה 5 פעולות ו-5 קרדיטים ב-Make. העלות של Claude נגבית בנפרד דרך חשבון Anthropic.

## חיבור לדשבורד

אחרי הבדיקה חיברתי את התרחיש לדשבורד הלידים. בכרטיס ליד יש כפתור "חשב ציון AI", והפונקציה ב-Supabase שולחת את מזהה הרשומה ל-webhook. לשם כך הוספתי לתרחיש שלב שישי, Webhook response, שמחזיר את הציון, כדי שהפונקציה תדע מתי החישוב הסתיים. הכתובת של ה-webhook שמורה כסוד ב-Supabase ולא בריפו.

בבדיקה דרך הפונקציה הליד L-1264 (מאיה שגיא) קיבל ציון 25, והתשובה חזרה אחרי 6.4 שניות.

התרחיש פעיל, יחד עם שני התרחישים האחרים של המטלה.
