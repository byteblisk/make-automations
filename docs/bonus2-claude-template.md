# בונוס 2

מצאתי בספריית התבניות של Make תבנית שמחברת webhook, את Claude ואת Airtable ("Send messages to Anthropic Claude and update records in Airtable using a custom webhook"), ויצרתי ממנה תרחיש אצלי. חיברתי אותה לטבלת הלידים של הדשבורד והוספתי לטבלה שני שדות, aiScore לציון ו-aiSummary לסיכום. כשמגיע מזהה של ליד, Claude קורא את הפרטים שלו, נותן ציון בין 1 ל-100 וכותב סיכום קצר בעברית, והתוצאה נשמרת בליד.

התבנית לא עבדה כמו שהיא. המודל שהוגדר בה, Claude 3.7 Sonnet, כבר לא זמין ב-Make, אז עברתי ל-Claude Haiku 5.5. השדה max_tokens היה שמור כטקסט ו-Anthropic החזירו שגיאה, אז שיניתי אותו למספר. התשובה של Claude מגיעה ל-Make עם כמה שדות. בתבנית, שלב ה-Parse JSON לקח את הטקסט מהפריט הראשון ברשימה Content, אבל אצלי הרשימה חזרה עם שני פריטים והראשון לא היה הטקסט, ולכן השלב קיבל ערך ריק ונכשל. בתשובה יש גם שדה בשם rawResponse, שבו נמצא הטקסט ש-Claude כתב, כלומר ה-JSON עם הציון והסיכום, אז חיברתי את Parse JSON לשדה הזה.

בבדיקה הראשונה שלחתי את הליד L-1263 של רון כהן. כל השלבים עברו, והוא קיבל ציון 55 עם הסיכום: "ליד מופנה עם תקציב גדול וערך של 25,000 ש"ח וענין ברור באתר תדמית וחיבור ל-CRM. עם זאת, הסטטוס עדיין חדש ואין פתיחות מיילים או ביקורים באתר, כך שהמעורבות נמוכה." הריצה עלתה 5 קרדיטים ב-Make, והשימוש ב-Claude נגבה בנפרד בחשבון Anthropic.

אחר כך חיברתי את התרחיש לדשבורד. בכרטיס של כל ליד יש עכשיו כפתור "חשב ציון AI", והפונקציה ב-Supabase שולחת את הליד ל-webhook. בשביל זה הוספתי לתרחיש עוד שלב שמחזיר את הציון, כדי שהדשבורד ידע מתי החישוב נגמר. את הכתובת של ה-webhook שמרתי בסודות של Supabase ולא בריפו. כשניסיתי את זה על L-1264 של מאיה שגיא, הציון חזר אחרי כ-6 שניות.
