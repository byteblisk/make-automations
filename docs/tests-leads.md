# בדיקות: תרחיש הלידים (בונוס 1)

23 בנובמבר 2026. כל בדיקה היא בקשת POST אמיתית לכתובת ה-webhook, ואחריה בדיקה של הטבלה ב-Airtable ושל הדשבורד. השמות בבדיקות בדויים.

אחרי לחיצה על "רענון" בדשבורד מופיעות 264 רשומות, ושלושת הלידים מופיעים בטבלה עם הנציג, המקור, הסטטוס והשווי שלהם.

## מה תוקן בדרך

1. **נציג ריק בבדיקה 1.** הנוסחה של הסבב השתמשה ב-mod, ו-Make מחשב שארית עם הסימן %. אחרי התיקון בבדיקות 2 ו-3 הנציג נקבע. לליד L-1262 הוסף הנציג אלה ידנית ב-Airtable.
2. **"Accepted" במקום מספר הליד בבדיקות 1 ו-2.** התרחיש היה מוגדר לעבד בקשות לפי הסדר. במצב הזה Make עונה לשולח מיד ומטפל בבקשה מאוחר יותר, ושלב התשובה נכשל עם האזהרה "Response can't be processed when scenario is not executed immediately on data arrival". אחרי שהעיבוד עבר למקביל, בדיקה 3 קיבלה את מספר הליד. האפיון עודכן לפני הבדיקה הזו.
